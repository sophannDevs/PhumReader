PhumiReader V2 · Design concept

Foundations: shadcn/ui + PhumiReader green

Built for Next.js + Tailwind + shadcn/ui. Neutral zinc surfaces, thin borders and 10 px corners; PhumiReader green is reserved for primary actions, progress and highlights. Every pattern below maps to a shadcn component so it can be implemented as-is.
